# UniBike-Bicycle-Sharing-System
A smart bicycle-sharing platform designed for university campuses.
It allows students to locate, book, and use bicycles conveniently, reducing travel time and promoting eco-friendly transport.

#Features:

User Dashboard – Search, book, and view bike availability.

Admin Panel – Manage bicycles, bookings, and user accounts.

Booking System – Reserve a bike in advance.

Usage Tracking – Record time for each ride.

File-Based data storage.


Tech Stack: 

Fontend: JavaFX (FXML,CSS)

Backend: Java

Database/Storage: File storage
